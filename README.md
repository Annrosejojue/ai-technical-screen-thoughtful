A lightweight customer support AI agent built for the Thoughtful AI Technical Screen.  
This project uses Streamlit, OpenAI, and a JSON-based Q&A dataset to answer common questions about Thoughtful AI’s automation agents.


- Loads predefined Q&A from a clean `data.json` file  
- Matches user questions using fuzzy search  
- Falls back to an OpenAI LLM when no match is found  
- Simple, clean Streamlit chat interface  
- Easy to extend with more questions or new data sources
